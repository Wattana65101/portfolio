JIB Online Examination System

ระบบสอบออนไลน์สำหรับผู้สมัครงานและพนักงาน พร้อมฝั่ง `Admin` สำหรับจัดการข้อสอบ/คำถาม/ตัวเลือก ดูผลและสถิติแบบกราฟ และฝั่งผู้ใช้สำหรับเข้าสอบ ส่งคำตอบและดูคะแนน (รวมข้อสอบอัตนัยที่ตรวจด้วย AI)

Key Highlights
  • พัฒนา Admin Dashboard แสดงสถิติผลสอบ พร้อมกราฟรายวัน/รายเดือน
  • สร้างจัดการ Exam, Question, Chioces และ import ข้อสอบ/คำถามจากข้อมูลในระบบ
  • รองรับข้อสอบอัตนัย เมื่อผู้ใช้ส่งคำตอบ ระบบให้ AI (Google Gemini) ช่วยตรวจแบบ background
  • รองรับ EQ exam และโครงสร้างแบบ merged exam (เก็บ snapshot ผ่าน merged_from พร้อมคัดกรอง/คำนวณตามกลุ่ม)
  • ทำสื่อ/รูปประกอบคำถามด้วยขั้นตอนประมวลผล (ย่อ/จัดรูป) ก่อนใช้งานในระบบ
  • จัดการผลสอบและประวัติด้วยฐานข้อมูล (เช่น exam_results เก็บ snapshot ของข้อมูลที่จำเป็น)
  • มี node-cron ดูแลข้อมูลอัตโนมัติ (ลบข้อมูลเก่าตามเงื่อนไข และคุม timezone)
Tech Stack
Node.js Express Sequelize (MySQL) JWT Google Gemini sharp xlsx Next.js (App Router) React Ant Design Recharts dayjs axios Docker Compose
